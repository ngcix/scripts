# Arch Linux Setup - Quick Deployment

## 🚀 Quick Start

1. **Read the docs:**
   - [README.md](README.md) — Overview
   - [TODO_CHECKLIST.md](TODO_CHECKLIST.md) — Action items

2. **Apply the fixes:**
   ```bash
   adb shell su -c 'bash HDD_FIX_QUICK.sh'
   adb push 00_init.sh /data/adb/service.d/
   ```

3. **Deploy to phone:**
   ```bash
   chmod +x /data/adb/service.d/00_init.sh
   adb shell su -c 'pkill -f "bash.*00_init.sh"; sleep 1; bash /data/adb/service.d/00_init.sh &'
   ```
